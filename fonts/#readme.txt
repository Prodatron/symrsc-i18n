C O D E P A G E   C H A R A C T E R   S E T S


For each of the SymbOS codepages, you will find the character sets for the
system font here.

2 = Latin 1     - f02lat1.fnt
3 = Japanese    - f03jpn.fnt
4 = Greek       - f04ell.fnt
5 = Cherokee    - f05chr.fnt
6 = Cyrillic    - f06cyr.fnt
7 = Latin 2     - f07lat2.fnt

You can edit a font by modifying its associated BMP image file. Next, run the
Python script FONT_BMP2SYSTEM.PY to regenerate the FNT file.
